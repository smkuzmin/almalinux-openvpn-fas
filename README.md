## AlmaLinux: Установка сервера OpenVPN и/или FAS

Предлагаю максимально автоматизированный способ установить **OpenVPN server** и/или [FAS](https://sites.google.com/site/smkuzmin/home/fas) на [AlmaLinux 10](https://go.lightnode.com/ru/tech/almalinux-vs-ubuntu).

**FAS** (**F**ile **A**llocation **S**ystem) - это простой интерфейс к веб-серверу для размещения файлов в Интернет. Если **FAS** установлен, **OpenVPN server** использует его для раздачи своих конфиг-файлов и windows-клиентов.

Установка возможна в 4 разных вариантах:
1. **OpenVPN server и FAS на одном сервере** - рекомендуется для ознакомления
2. **OpenVPN server и FAS на разных серверах** - рекомендуется для реального использования
3. **Только OpenVPN server** - без хостинга windows-клиентов, конфиг-файлов клиентов и любых других файлов
4. **Только FAS** - хостинг файлов

Предполагается, что сервер устанавливается в локальной сети **10.x.y.0/255.255.255.0** и имеет один сетевой интерфейс **eth0**. Но ничто вам не мешает сменить адресацию, добавить внешний интерфес, и т.д.

Также предполагается, что снаружи проброшены **tcp**-порты: **81** (для **OpenVPN server**) и **80**, **443** (для **FAS**).

### Установка AlmaLinux

1. Скачиваем iso-образ [AlmaLinux 10 Minimal](https://repo.almalinux.org/almalinux/10/isos/x86_64/AlmaLinux-10.0-x86_64-minimal.iso).
2. Устанавливаем его на сервер (2 CPU cores / 2–4 GB RAM / 20 GB storage):
   - **Язык в процессе установки**: Русский / Русский (Россия)
   - **Место установки**: Автоматическое разбиение диска
   - **KDUMP**: \[ \] Включить kdump
   - **Имя сети и узла**:
      - **Ethernet (eth0)** \[x\] -> **\[ Настроить \]**
        - **\[ IPv4 Settings \]**
          - **Method**: Manual
          - **Addresses** -> **\[ Add \]** -> **Address**: 10.x.y.z -> **Netmask**: 255.255.255.0 -> **Gateway**: 10.x.y.1
          - **DNS servers**: 8.8.8.8 1.1.1.1
          - **Search domains**: domain.local  *# указываем локальный домен - по нему будет идти поиск коротких имен*
        - **\[ IPv6 Settings \]** -> **Method**: Disabled
        - **\[ Save \]**
     - **Имя узла**: openvpn.domain.com -> **\[ Применить \]**  *# указываем внешнее имя - на него будем получать сертификат Let's Encrypt*
     - **СЕТЬ И ИМЯ УЗЛА**: **\[ Готово \]**
   - **Дата и время**: Европа / Самара
   - **Учетная запись root**:
       \[x\] Включить учетную запись root
       \[x\] Разрешить вход пользователем root с паролем через ssh
   - **\[ Начать установку \]**
3. Проверяем Интернет:
     ```powershell
     ping ya.ru
     ```
4. Если Интернет не работает, донастраиваем сеть:
     ```poershell
     nmtui
     ```

### Обновление ядра AlmaLinux (опционально)

Пропустите обновление ядра, если уже устанавливали по этой инструкции и получили какие-либо проблемы.

1. Обновляем ядро:
     ```powershell
     yum -y update kernel
     ```
2. Перезагружаемся:
     ```powershell
     reboot
     ```

### Установка OpenVPN server и/или FAS

1. Заходим на сервер и запускаем установщик:
     ```powershell
     yum -yq install tar && cd ~ && wget https://github.com/smkuzmin/almalinux-openvpn-fas/raw/refs/heads/main/almalinux10.tar.gz && for f in almalinux10*.tar.gz; do tar xzf $f; done && cd almalinux10 && ./go
     ```
    В меню выбираем нужные пакеты (рекомендуемые уже выбраны) и жмем **Install selected**.
4. После установки пакетов требуется перезагрузка:
     ```powershell
     reboot
     ```

### Подключение второго диска для FAS (опционально)

На этом этапе можно подключить отдельный диск с каталогом **html** - в нем будут храниться (или уже хранятся) файлы веб-сервера.

1. Добавляем на сервер второй диск (размером 500 Гб, например).
2. Ищем второй диск по его размеру:
     ```powershell
     disk-list
     ```
    Из вывода команды берем имя диска с размером **500G** - у меня это **/dev/sdb**.
3. Если второй диск новый - очищаем его:
     ```powershell
     disk-clean /dev/sdb
     ```
    а также создаем раздел **/dev/sdb1** и файловую систему **XFS** на нем:
     ```powershell
     disk-init /dev/sdb
     ``` 
4. Монтируем второй диск (точнее его раздел **/dev/sdb1**) в **/mnt/disk2**:
     ```powershell
     disk-mount /dev/sdb /mnt/disk2
     ```
5. Создаем каталог **/mnt/disk2/html** на нем:
     ```powershell
     mkdir -p /mnt/disk2/html
     ```
6. Создаем на каталог **/mnt/disk2/html** ссылку **/var/www/html**:
   ```powershell
   ~/almalinux10/tuning/MakeLinks
   ```

### Настройка OpenVPN server (опционально)

По умолчанию в VPN заворачивается весь трафик. Если нужно делать это выборочно, то приступаем к настройке:

1. Открываем файл:
     ```powershell
     mcedit /etc/openvpn/server/server.conf
     ```
2. Находим и комментируем строку:
     ```powershell
     push "redirect-gateway"
     ```
3. Добавляем нужные сети, например сеть 10.0.0.0/8:
     ```powershell
     push "route 10.0.0.0 255.0.0.0"
     ```
4. Перезапускаем службу OpenVPN:
     ```powershell
     ovr  # systemctl restart openvpn-server@server
     ```
5. Проверяем статус службы:
     ```powershell
     ovs  # systemctl status openvpn-server@server
     ```

### Использование OpenVPN server

1. Создаем нового пользователя:
     ```powershell
     openvpnuser add user
     ```
    и получаем:
   - ссылки на официальные [Android](https://play.google.com/store/apps/details?id=de.blinkt.openvpn)/[iOS](http://apps.apple.com/nl/app/openvpn-connect/id590379981)/[macOS](http://openvpn.net/downloads/openvpn-connect-v3-macos.dmg)-клиенты
   - ссылку на собственный [Windows-клиент](https://sites.google.com/site/smkuzmin/home/silent_install). Его преимущества: он для всех версий Windows, установка без вопросов, конфиг-файл уже внутри. Можно выбрать формат установщика: **EXE** - запускается сразу, или **ZIP** - нужно распаковать и запустить **install.bat**. В обоих случаях на время установки нужны права администратора.
   - ссылку на конфиг-файл (**\*.ovpn**)
2. Качаем по ссылке нужный клиент и устанавливаем его. Windows-клиент просто запускаем и пользуемся. Для остальных клиентов необходимо импортировать конфиг-файл.
3. Каталоги и файлы:
   - **/etc/openvpn/** - все настройки
   - **/etc/openvpn/client/** - конфиг-файлы клентов и Windows-клиенты
   - **/etc/openvpn/server/server.conf** - основной конфигурационный файл сервера
   - **/etc/openvpn/openvpnuser.pwl** - список паролей, которые используются при создании новых пользователей, если пароль не был задан явно
   - **/etc/openvpn/openvpnuser.cfg** - настройки команды openvpnuser
4. Справка по управлению пользователями:
     ```powershell
     openvpnuser -h
     ```

### Использование FAS

Учетка **admin** является единственной в системе учеткой с правами администратора. Она предназначена для управления пользователями и их файлами. Также у нее нет возможности загрузки файлов на сервер.

1. Получаем пароль учетки **admin**, выполнив команду на сервере **FAS**:
     ```powershell
     fasuser
     ```
    и заходим с этой учеткой и паролем в веб-интерфейс **FAS**: http://<ваш_сервер>/. В нем уже можно для размещения файлов создать пользовательскую учетку.
2. Управлять пользователями **FAS** можно также из консоли. Справка по управлению пользователями:
     ```powershell
     fasuser -h
     ```
